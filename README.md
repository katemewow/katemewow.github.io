# katemewow – AdSense story

A personal article by Ekaterina.

Website: https://katemewow.github.io/adsense-story/

This repository contains a plain HTML website for GitHub Pages.

Publishing: Settings → Pages → Deploy from a branch → main → / (root).

- Article: `adsense-story/index.html`
- Styles: `assets/css/article.css`
- X post link: `assets/js/config.js`
- Profile photo: `assets/avatar.webp`
- Screenshots: `assets/evidence/`

No build step, package manager, or third-party scripts are needed.
